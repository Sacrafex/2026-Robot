# 2026 Robot

## Project Description
This 2026 Robot is designed to compete in the FRC Rebuilt challenge having to score yellow balls into a giant hopper.

## Features
- Autonomous navigation using PathPlanner & Limelight Position
- WebServer dashboard for control and info
- Automatic Aim and Fire Shooter Code

- Access the dashboard at `http://10.28.39.2:5809` for the Web Dashboard.
